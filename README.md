# wallpaper-plugin — DSH 美化插件

中文 | English: [README.en.md](README.en.md)

DSH（DeepSeek Harness）第三方插件：**换肤 + 壁纸 + 中英双语**。装好之后设置页会多一个「外观预设」。

- **换肤**：预设墙 + 27 个语义旋钮 + 369 个令牌逐项编辑 + CSS 补丁 + 原生主题注册
- **壁纸**：素材库 / 图片链接 / 内置渐变 / 定时轮换 / 图层合成（含多 GIF 时间轴）
- **协同与分发**：13 个 AI 工具、分享链接与分享码、ZIP 完整交付、中/英切换

## 功能

### 换肤

- **预设墙**：卡片一键切换 + 封面 + diff 告警；**收藏 / 只看收藏 / 换一个试试**
- **旋钮层**：27 个语义旋钮 / 6 类（空间定位、背景层次、强调色、文字可读性、交互反馈、布局排版）。
  颜色旋钮默认**一次写亮暗两套**，勾「明暗分别设置」才并排；束内被手改过的令牌会标「束内已单独调整」，不会静默覆盖
- **原始令牌**：369 个令牌表单，中文描述、分组染色（一次改一组）、搜索、撤销、安全等级分级
- **CSS 补丁**：`[data-*]` 锚点白名单 + 禁止花括号，行内校验、即时预览、可撤销
- **原生主题注册**：把预设注册成 DSH 主题，直接出现在「设置 → 外观」列表
- **出厂预设「默认」**：36 个令牌，覆盖 20/27 个颜色旋钮，自带满幅 3:1 封面与暗色专用壁纸

### 壁纸

- **素材库**：上传图片（≤20MB/个，库上限 100 个）→ 分配给三部件（16:9 聊天背景 / 1:1 设置卡 / 1:5 侧栏海报），
  按固定比例裁剪、明暗分别配置、不透明度
- **壁纸 2.0**：每个部件可选**本地素材 / 图片链接（http/https）/ 内置 8 款渐变**。
  链接与渐变不做裁剪（没有原始像素坐标语义）；支持深色链接与深色渐变
- **定时轮换**：2–20 条链接、5 分钟–7 天；页面隐藏不切换、回前台补切、编辑草稿时不切换。
  配置只存本机，**不随预设/分享走**
- **图层合成壁纸**：多张小图拼贴；多 GIF 按时间轴合成输出真动图；单个动图场景自动**分层输出**

### 协同与分发

- **AI 工具**：13 个 `preset_*` / `asset_*` 工具（对话式换肤：创建 / 应用 / 微调 / 自检 / 回滚）
- **分享链接 / 分享码**：URL hash 载荷，跨机器可粘贴；带令牌双值 + CSS 补丁 + 部件裁剪 + 主题注册，
  素材只带引用并显式告知缺失数量；导入只入库、不自动应用
- **ZIP 三件套**：预设 + 封面 + **全部素材内嵌**，导入完整还原（含分层规格）
- **中英双语**：界面文案随语言切换（墙头 EN / 中文，选择记忆在本机）；令牌中文描述等内容型数据不翻译

## 安装

```sh
# 装入 profile（构建产物随仓库提交，GitHub 安装开箱即用）
dsh plugin --profile <name> add github:Ayase34/wallpaper-plugin
```

### 插件配置（可选）

在 profile 的 `cordis.patch.yml` 写：

```yaml
- id: wallpaper-plugin
  config:
    presetsDir: C:/你的预设目录      # 可选；默认 <dshHome>/.ui-presets
    assetsDir: C:/你的壁纸库目录     # 可选；默认 <presetsDir>/assets
```

## 快速开始

1. 设置 →「外观预设」→ 点「默认」应用（自带三张壁纸与封面）
2. 换壁纸：工作室「素材与部件」→ 上传图片 / 贴图片链接 / 选内置渐变 → 「设为聊天背景」
3. 微调：顶部旋钮层拖一拖；不够细就展开「原始令牌」
4. 分享：卡片「分享」→ 复制分享码；对方在「导入分享码」粘贴
5. 语言：墙头 **EN / 中文** 一键切换

## 开发

```sh
npm run build                # 构建 lib/core.mjs + .dsh-plugin/*（需 DSH_CHECKOUT）
npm run check:client         # 产物一致性守卫（--check）
npm test                     # 构建 + 单测（257 项）
node scripts/selfcheck.mjs   # 一键自检：构建一致性/单测/安装声明/数据完整性
node scripts/run-regression.mjs  # 全量 e2e（31 脚本；需 spike profile + 环境变量）
```

- **构建依赖**：`DSH_CHECKOUT` 必须显式指向 deepseek-harness checkout（vendor/schemastery + vendor/cosmokit
  打包自包含——静态外部 import 会导致桌面端无法启动）；目录生成同理：`node scripts/gen-catalog.mjs --dsh <checkout>`
- **e2e 环境变量（必填）**：`UIP_PLAYWRIGHT_DIR`（playwright 包目录）、`UIP_CHROMIUM`（chromium 可执行文件）；
  `DSH_HOME` 指向隔离测试目录（e2e-home），测试一律用独立 spike profile + 端口 3180，不触碰正式 profile
- **Token 目录版本**：`src/core/catalog-data.ts` 由 DSH 0.1.0-rc.5 的 token 表生成；宿主升级后需重跑生成脚本并提交 diff
